# 全站错误码总表

> 本文件是全站错误码的唯一数据汇总。各接口文档的错误码字典只列**本接口可能出现**的码，完整清单以本文件与代码中的 `XxxErrorCode` 枚举为准。

## 分段规范

错误码为 5 位数字，按「首位大类 + 第 2-3 位分类码 + 第 4-5 位具体错误」分段：

| 首位 | 大类 | 第 2-3 位含义 | HTTP 状态码 |
| ---- | ---- | ------------- | ----------- |
| 0 | 成功 | — | 200 |
| 2 | 业务错误 | 模块码（`21` 订单、`22` 支付） | 400 |
| 3 | 第三方 / 下游服务错误 | 渠道码（`30` 通用） | 500 |
| 4 | 客户端错误 | **HTTP 状态码的后两位**（见下） | 取错误码前 3 位 |
| 5 | 系统错误 | 子类码（`00` 通用系统、`01` 存储） | 500 |

`4` 段特殊：第 2-3 位不表示模块，而是直接写 HTTP 状态码的后两位，所以**错误码前 3 位就是它返回的 HTTP 状态码**：

| 段位 | 含义 | HTTP 状态码 | 举例 |
| ---- | ---- | ----------- | ---- |
| `400xx` | 参数 / 请求格式错误 | 400 | `40002` 参数缺失 |
| `401xx` | 鉴权失败 | 401 | `40100` 未登录 |
| `404xx` | 资源不存在 | 404 | `40400` 资源不存在 |
| `409xx` | 冲突 / 幂等 | 409 | `40901` 重复提交 |
| `429xx` | 限流 | 429 | `42901` 请求过于频繁 |

HTTP 状态码由错误码统一推导，接口不单独约定（实现见 `GlobalExceptionHandler#resolveHttpStatus`）：

- `4` 开头：取前 3 位作为状态码；上表未列举的段位兜底 400。
- `2` 开头：400。
- `3` / `5` 开头：500。

分类码分配：

| 段位 | 归属 | 错误码定义 |
| ---- | ---- | ---------- |
| 21 | 订单模块 | `OrderErrorCode` |
| 22 | 支付模块 | `PayErrorCode` |
| 30 | 下游通用 | `DownstreamErrorCode` |

新模块从 `23` 起递增分配，新下游渠道从 `31` 起递增分配。

## 一、通用错误

跨模块复用，与具体业务无关，定义于 `shared.error` 包。

### 1.1 参数与请求（`400xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 40001 | 400 | 缺少请求头（message 中带具体请求头名） | `CommonErrorCode.MISSING_REQUEST_HEADER` |
| 40002 | 400 | 参数缺失 / 参数校验失败 / 请求体格式错误 / 参数类型不正确 | `CommonErrorCode.PARAM_MISSING` |

### 1.2 鉴权（`401xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 40100 | 401 | 未登录 | `CommonErrorCode.UNAUTHORIZED`（鉴权拦截器） |
| 40101 | 401 | 令牌无效 | `AuthErrorCode.TOKEN_INVALID` |
| 40102 | 401 | 令牌已过期 | `AuthErrorCode.TOKEN_EXPIRED` |
| 40103 | 401 | 令牌已被禁用 | `AuthErrorCode.TOKEN_DISABLED` |

### 1.3 资源不存在（`404xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 40400 | 404 | 资源不存在 | `CommonErrorCode.NOT_FOUND` |

### 1.4 冲突与幂等（`409xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 40901 | 409 | 重复提交，请勿重复操作 | `CommonErrorCode.DUPLICATE_SUBMIT` |

### 1.5 限流（`429xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 42901 | 429 | 请求过于频繁 | `CommonErrorCode.TOO_FREQUENT` |

### 1.6 系统（`500xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 50000 | 500 | 系统繁忙，请稍后重试（未预期异常兜底） | `CommonErrorCode.SYSTEM_ERROR` |

### 1.7 数据库 / 存储（`501xx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 50100 | 500 | 数据库未启用 | `CommonErrorCode.DB_NOT_ENABLED` |
| 50101 | 500 | 数据库访问异常（对外 message 为「系统繁忙，请稍后重试」） | `CommonErrorCode.MYBATIS_SYSTEM_EXCEPTION` |

### 1.8 下游 / 第三方服务（`30xxx`）

| 错误码 | HTTP 状态码 | 说明 | 定义位置（枚举常量） |
| ------ | ----------- | ---- | -------------------- |
| 30001 | 500 | 下游服务未配置 | `DownstreamErrorCode.DOWNSTREAM_NOT_CONFIGURED` |
| 30002 | 500 | 下游服务不可用 | `DownstreamErrorCode.DOWNSTREAM_UNAVAILABLE` |

## 新增错误码流程

1. 判断大类：通用（`4xxxx` / `5xxxx` / `3xxxx`，放入 `shared.error`）还是业务（`2xxxx`，放入对应领域的 `XxxErrorCode`）。
2. 业务错误在所属模块段位内取未使用的最小后两位；新模块按上表规则申请新模块码，避免冲突。
3. 在本文件对应小节按错误码升序补充一行。
4. 同步更新受影响接口文档的错误码字典。
